# C Learning Path

Este repositório reúne meu **processo de aprendizado na linguagem C**, abrangendo desde **fundamentos de programação** e **desafios práticos** até **estruturas de dados, algoritmos e complexidade computacional**.

O objetivo é consolidar conhecimentos, praticar lógica de programação e construir uma base sólida em C e em conceitos fundamentais da Ciência da Computação.

---

## 📚 Conteúdos Abordados

### 🔹 Fundamentos de Programação
- Variáveis e tipos de dados  
- Estruturas condicionais  
- Estruturas de repetição (`for`, `while`, `do-while`)  
- Funções  
- Vetores e strings  
- Ponteiros  
- Entrada e saída de dados  

### 🔹 Desafios e Resolução de Problemas
- Exercícios de lógica  
- Desafios de programação  
- Raciocínio algorítmico  
- Otimização de código  

### 🔹 Estruturas de Dados
- Vetores e alocação dinâmica  
- Listas encadeadas  
- Pilhas  
- Filas  
- Árvores (conceitos básicos)  
- Tabelas hash (introdução)  

### 🔹 Algoritmos / Esses algoritmos encontram-se no repositório de benchmark
- Algoritmos de busca  
- Algoritmos de ordenação  
- Recursão  
- Estratégias gulosas (introdução)
